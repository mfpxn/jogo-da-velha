
# Jogo da Velha em Python

Projeto desenvolvido para a disciplina de Coding da UNINASSAU.

## Objetivo

Desenvolver um Jogo da Velha em Python utilizando
conceitos fundamentais de programacao.

## Integrantes e responsabilidades

DEV 1 - Tabuleiro:
- Criacao da matriz 3x3
- Exibicao do tabuleiro
- Leitura e validacao das jogadas
- Verificacao de casas ocupadas
- Atualizacao da matriz

DEV 2 - Logica:
- Controle dos jogadores X e O
- Alternancia das jogadas
- Verificacao de vitoria
- Verificacao de empate
- Encerramento da partida

DEV 3 - Menu e campeonato:
- Menu principal
- Placar acumulado
- Estatisticas
- Campeonato melhor de tres
- Controle de novas partidas

## Requisitos

- Python 3

## Como executar

Abra o terminal na pasta do projeto e execute:

    python3 jogo_da_velha.py

## Menu principal

1 - Iniciar partida
2 - Campeonato Melhor de 3
3 - Ver placar acumulado
4 - Ver estatisticas
5 - Sair

## Arquivos do projeto

- dev1.py: desenvolvimento individual do DEV 1
- jogo.py: desenvolvimento individual do DEV 2
- dev3.py: desenvolvimento individual do DEV 3
- jogo_da_velha.py: arquivo executavel da entrega
- README.md: documentacao do projeto
